# Problem

People who want to manage their personal finances often struggle to keep track of
where their money goes. Without an organized way to monitor income, expenses, and
budgets, it can be difficult to understand spending habits and stay within
financial goals.

# Initial requirements

- R1. Allow users to record income and expenses.
- R2. Allow users to categorize transactions.
- R3. Display a list of recorded transactions.
- R4. Calculate total income, expenses, and remaining balance.
- R5. Allow users to set monthly spending budgets by category.
- R6. Display how much of each budget has been used.
- R7. Save financial information locally so it is available when the application is
  reopened.
